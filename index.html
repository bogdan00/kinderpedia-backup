How It Works & Capabilities

⚡ File System Access API

Streams multi-gigabyte photos and video files directly from network sockets straight to disk handles, keeping browser memory under 30 MB.

🛡️ Adaptive Rate Limiter

Uses AIMD + soft-floor request pacing to stream metadata at maximum velocity without triggering HTTP 429 quota bans.

🔄 Instant Resume

Checks local files and JSON manifests on startup. Skips existing photos in <1 second if you pause or resume later.

🎬 Pure-JS Video Remuxing

Uses in-browser Web Workers with mux.js to assemble Vimeo HLS streams into playable standard MP4 files without native FFmpeg.
